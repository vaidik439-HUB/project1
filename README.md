# Fundamental Booster

## Project Overview
This project is a beginner-friendly Python program designed to demonstrate the fundamentals of:

- Variables
- Data types
- User input
- Type conversion
- Basic calculations
- Memory locations in Python

The program collects user information, processes the data, and displays a formatted summary while showing each variable’s data type and memory address using Python’s built-in functions.

---

# Objectives
The project aims to help learners:

- Understand how variables work in Python
- Learn different data types (`str`, `int`, `float`)
- Practice accepting user input
- Perform simple calculations
- Explore memory management using `id()`
- Identify variable types using `type()`

---

# Features

## Welcome Message
The program starts with a friendly introduction explaining its purpose.

## User Information Collection
The user is prompted to enter:

- Name (String)
- Age (Integer)
- Height (Float)
- Favourite Number (Integer)

## Data Processing
The program performs simple processing such as:

- Calculating the user’s estimated birth year
- Demonstrating type conversion
- Displaying memory locations of variables

## Variable Analysis
For every variable, the program displays:

- Variable Name
- Value
- Data Type
- Memory Address

## Display Results
Print a summary of the user's information,formatted in a user friendly way.
Display messages showing how data types were converted where applicable.


## Exit Message
End with a thank-you message and encourage the user to explore python further.
